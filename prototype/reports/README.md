# Prototype report examples

These CSV files are sample downloads for the clickable HTML prototype. They contain synthetic data only and are not connected to the application database.

- `executive-attendance-summary.csv` — executive-level attendance rates and missing-record summary.
- `active-breakdown-by-category.csv` — class/category active-student breakdown based on the existing workbook dashboard concept.
- `attendance-monthly-sheet.csv` — operator-facing monthly attendance export example compatible with the transitional UiPath workflow.
- `timetable-by-instclass.csv` — By Instructional Class timetable export from the Amend 4-up draft.
- `timetable-by-teacher.csv` — By Teacher timetable export from the same draft.

The report buttons in `prototype/index.html` download these files directly.
